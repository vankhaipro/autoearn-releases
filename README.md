## 🔒 AutoEarn Proxy — bản 1.4.0

Biến tài khoản ProtonVPN thành dàn proxy SOCKS5 / HTTP cho GPM Login, AdsPower, trình duyệt...

| Máy | Tải về |
| --- | --- |
| Windows 10/11 — bản cài đặt | [AutoEarnProxy-1.4.0-win-x64-setup.exe](https://github.com/vankhaipro/autoearn-releases/releases/download/proxy-v1.4.0/AutoEarnProxy-1.4.0-win-x64-setup.exe) |
| Windows 10/11 — bản chạy luôn (portable) | [AutoEarnProxy-1.4.0-win-x64-portable.exe](https://github.com/vankhaipro/autoearn-releases/releases/download/proxy-v1.4.0/AutoEarnProxy-1.4.0-win-x64-portable.exe) |
| macOS chip Intel | [AutoEarnProxy-1.4.0-mac-x64.dmg](https://github.com/vankhaipro/autoearn-releases/releases/download/proxy-v1.4.0/AutoEarnProxy-1.4.0-mac-x64.dmg) |
| macOS chip Apple (M1–M4) | [AutoEarnProxy-1.4.0-mac-arm64.dmg](https://github.com/vankhaipro/autoearn-releases/releases/download/proxy-v1.4.0/AutoEarnProxy-1.4.0-mac-arm64.dmg) |
| Extension Chrome (tự cập nhật % tải) | [AutoEarnProxy-Chrome-Extension.zip](https://github.com/vankhaipro/autoearn-releases/releases/download/proxy-v1.4.0/AutoEarnProxy-Chrome-Extension.zip) |

- **Mac lần đầu mở:** kéo app vào Applications → chuột phải → **Open** → **Open**. Nếu báo "damaged": `xattr -dr com.apple.quarantine "/Applications/AutoEarn Proxy.app"`
- **Windows:** SmartScreen cảnh báo → **More info** → **Run anyway**.
- **Extension:** giải nén → `chrome://extensions` → bật Developer mode → **Load unpacked** (hoặc bấm *Cài extension* trong app).
